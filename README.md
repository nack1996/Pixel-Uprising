# -Pixel-Uprising-0.1.0
Pixel Uprising is an unofficial, non-commercial fan-made engine that lets you play again a 2010 iOS game on Mac and Windows. This item contains ONLY the engine. It does not include any graphics, music, sound effects, videos, texts or data from the original game. To play, you need your own copy of the original iOS game file (.ipa), version 1.4.5.
